# Gamification

NUMA should feel as motivating as a game — but **money truth always wins**.

## Non-negotiable

1. Gamification is a **presentation + progress layer** on top of the finance engine.
2. It must never invent a second budget, balance, or ledger.
3. Live “plus / minus today” comes from the same inputs as safe-to-spend and spending.
4. Rewards, ranks, and shareable scores are derived from deterministic outcomes (on-plan days, surplus vs plan), not from guessing or vanity taps.
5. Sharing shows **progress stats**, never raw bank details, unless the user explicitly chooses to reveal amounts.

## Core loop (v1)

1. User has a **today plan** (safe-to-spend today).
2. Each confirmed expense updates **spent today**.
3. UI shows live pulse:
   - **Plus** — under plan
   - **Jämnt** — exactly on plan
   - **Minus** — over plan (future daily allowance recalculates; no shame spiral)
4. Staying on track accumulates **on-track days** → ranks unlock.

## Later

- Badges / small celebrations for streaks and surplus weeks
- Optional share card (“7 dagar på rätt spår”) without leaking account numbers
- Camera / screenshot imports feed the **same** pulse after confirmation

## What we will not do

- Points that can be bought or farmed without real financial discipline
- Fake crypto/leaderboard aesthetics
- Letting OCR auto-confirm and then award ranks on uncertain data
